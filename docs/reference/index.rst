API reference
=============

The reference is generated from the docstrings of the package with Sphinx autodoc (NumPy style, as in amaranth-soc and amaranth-boards). The examples in the
docstrings are run by ``sphinx-build -b doctest``. The manuals in the other pages explain how the parts fit together; this part lists the public classes, functions and exceptions of the modules below. Module-level constants (the operand constants of the builder such as ``X``, ``Y`` and ``PINS``, and the opcode constants of ``pioweave.data``) are explained in the manuals, not listed here.
